# BackTooL
Вспомогательная утилита для настройки, очистки и проверки вашего ПК

</div>

> [!IMPORTANT]
> ### РАННИЙ ДОСТУП
> Проект находится в стадии активной разработки. Все обнаруженные баги и недочеты будут со временем исправлены.

> [!WARNING]
> ### ЛОЖНЫЕ СРАБАТЫВАНИЕ
> Антивирусы могут ложно срабатывать на утилиту из-за работы с системными скриптами (Например: Отключение Windows Defender). И
> Из-за этого утилита может работать некорректно, или некоторые её функции могут быть недоступны.
> #### Рекомендуется добавить утилиту в "Исключение" вашего антивируса.



## Возможности

- Проверка диска на чтение, запись и скорость
- Полная информация о ПК
- Проверка флешки на наличие поддельного объёма
- Завершение зависших программ | Завершает принудительно зависшую программу
- Анализ больших файлов | Показывает самые многовесущие файлы на компьютере
- Управление автозагрузкой | Анализирует автозагрузку и подсказывает, что можно отключить, а что лучше оставить включённым
- Очистка временных файлов (temp)
- Отключение Windows Defender 
- Удаление OneDrive 

## Требования

- Windows 11

## Использование
Запустите `BackTooL.exe` от имени администратора и выберите необходимое действие.

## Компиляция исходного кода
### Требования

Перед компиляцией убедитесь, что у вас установлены:

- Go — версия 1.25.5 или выше
- Git — если вы клонируете репозиторий

Команды для компиляции:
```bash
    git clone https://github.com/lock3d9/btl-official-ru.git
    cd btl-offical-ru
    go mod download
    task build
```
